# 範例檔案說明

本資料夾用於存放範例的輸入檔案和模板。

## 所需檔案

### 1. Master_Log.xlsx (必須)
- **用途**: 測試數據來源
- **位置**: 和 main.py 同一資料夾
- **格式**: Excel 2016+ (.xlsx)
- **欄位**: 
  - 測項名稱
  - 測試狀態
  - 開始時間
  - 結束時間
  - Physical Damage
  - Functional Check

### 2. Template.doc (必須)
- **用途**: Word 報告模板
- **位置**: 和 main.py 同一資料夾
- **格式**: Word 97-2003 (.doc) 或現代格式 (.docx)
- **內容要求**:
  - 包含佔位符: {Report_Title}, {Report_Date}, {Author}
  - 包含 3.1 測項結果表
  - 包含 4.x 詳細結果表
  - 建議包含目錄 (TOC)

## 輸出檔案

運行 main.py 後會自動生成:

### 1. Final_Report.docx
- **用途**: 生成的最終報告
- **位置**: 同一資料夾
- **格式**: Word 2016+ (.docx)

### 2. report_generation.log
- **用途**: 詳細執行日誌
- **位置**: 同一資料夾
- **內容**: 包含每個處理階段的詳細訊息和錯誤

## 建立範例檔案步驟

### 創建 Master_Log.xlsx

使用 Excel 建立如下結構:

```
| 測項名稱 | 測試狀態 | 開始時間 | 結束時間 | Physical Damage | Functional Check |
|---------|---------|---------|---------|----------------|------------------|
| PC-001 基本功能 | 通過 | 2024-01-15 09:30 | 2024-01-15 10:15 | 無損傷 | 正常 |
| PC-002 壓力測試 | 跳過 | - | - | - | - |
| PC-003 環境適應性 | 通過 | 2024-01-15 11:00 | 2024-01-15 11:45 | 無損傷 | 正常 |
```

### 創建 Template.doc

使用 Word 建立包含以下內容的模板:

1. **標題部分**:
   ```
   測試報告
   標題: {Report_Title}
   日期: {Report_Date}
   作者: {Author}
   ```

2. **3.1 測項結果表**:
   ```
   | 測項名稱 | 開始時間 | 結束時間 | 狀態 |
   |---------|---------|---------|------|
   |  |  |  |  |
   |  |  |  |  |
   ```

3. **4.1 詳細結果表 (Physical Damage)**:
   ```
   | Physical Damage | 檢查結果 |
   |-----------------|---------|
   |  |  |
   |  |  |
   ```

4. **4.2 詳細結果表 (Functional Check)**:
   ```
   | Functional Check | 檢查結果 |
   |------------------|---------|
   |  |  |

   ```

## 常見問題

### Q: 可以不用 Master_Log.xlsx，直接用其他檔名嗎?

**A**: 目前不行。工具使用硬編碼的檔名。如需改變，編輯 main.py 的最上方:

```python
EXCEL_FILE = "你的檔名.xlsx"
```

### Q: Template.doc 可以是 .docx 嗎?

**A**: 可以，但要確保模板可以被 python-docx 開啟。建議首先用 .doc 或 .docx 測試。

### Q: 如果測項狀態不是"跳過"會怎樣?

**A**: 只有狀態為"跳過"的項目會被刪除章節。其他狀態（如"通過"、"失敗"）會保留。

### Q: 能否添加更多欄位?

**A**: 可以，但需要在 main.py 中修改 REQUIRED_COLUMNS 和相應的表格填充邏輯。

**使用提示**: 建議先建立簡單的範例檔案測試，確認工具運作無誤後再使用正式報告模板。
