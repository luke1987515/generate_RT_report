# 快速使用指南 (Quick Start)

## 📋 準備工作（第一次使用）

### 1. 安裝 Python 依賴

```bash
pip install python-docx openpyxl pywin32
```

### 2. 準備測試數據 Excel 檔案

**檔名**: `Master_Log.xlsx`  
**位置**: 和 `main.py` 同一資料夾  

建立 Excel 檔案，包含以下欄位：

```
測項名稱 | 測試狀態 | 開始時間 | 結束時間 | Physical Damage | Functional Check
```

**範例**:
```
機種型號檢測        | 通過 | 2024-01-15 09:00 | 2024-01-15 09:30 | 無 | 正常
基本功能測試        | 通過 | 2024-01-15 10:00 | 2024-01-15 10:45 | 無 | 正常
壓力測試           | 跳過 | -    | -    | -  | -
```

### 3. 準備 Word 報告模板

**檔名**: `Template.doc` 或 `Template.docx`  
**位置**: 和 `main.py` 同一資料夾  

Word 模板中必須包含：
- 佔位符: `{Report_Title}`, `{Report_Date}`, `{Author}`
- 表格: "3.1 Test Item Result" 
- 目錄 (TOC)

---

## ▶️ 執行步驟

### 第 1 步: 開啟命令列

```
Win+R → cmd → 進入資料夾
```

### 第 2 步: 運行工具

```bash
python main.py
```

### 第 3 步: 查看結果

- ✅ **Final_Report.docx** - 生成的報告
- 📋 **report_generation.log** - 執行日誌

## 📊 Excel 欄位說明

| 欄位 | 類型 | 說明 | 範例 |
|-----|------|------|------|
| **測項名稱** | 文字 | 測試項目的名稱 | 基本功能測試 |
| **測試狀態** | 文字 | "通過" / "失敗" / "跳過" | 通過 |
| **開始時間** | 文字 | 測試開始時間 | 2024-01-15 09:00 |
| **結束時間** | 文字 | 測試結束時間 | 2024-01-15 09:45 |
| **Physical Damage** | 文字 | 物理損傷檢查 | 無損傷 |
| **Functional Check** | 文字 | 功能檢查結果 | 正常 |

**重點**: 測試狀態為 "跳過" 的項目會自動從報告中刪除相應章節。

## 🔄 7 階段處理流程

```
1️⃣  驗證     → 檢查 Excel、Word 是否存在
2️⃣  讀取     → 從 Excel 讀取測試數據
3️⃣  替換     → 替換 {Report_Title} 等佔位符
4️⃣  清理     → 刪除 "跳過" 測項的章節
5️⃣  優化     → 清理空標題和孤立段落
6️⃣  填充     → 在表格中填入測試數據
7️⃣  更新     → 更新報告目錄 (TOC)
       ↓
    ✅ Final_Report.docx
```

## ⚠️ 常見問題

### Q: 執行時出現「Excel 檔案不存在」

**A**: 檢查:
1. 檔名是否為 `Master_Log.xlsx`（區分大小寫）
2. 檔案是否和 `main.py` 在同一資料夾
3. Excel 檔案是否被其他程式開啟

### Q: 報告中有些內容沒填上

**A**: 檢查:
1. Excel 欄位名稱是否正確（繁體中文）
2. 表格結構是否符合預期
3. 查看 `report_generation.log` 檢查錯誤訊息

### Q: Word 更新目錄失敗

**A**: 這是正常現象，報告仍會生成。解決方案:
1. 確保 Word 已安裝
2. 手動開啟 `Final_Report.docx` → 右鍵目錄 → 更新

### Q: 能否改變檔名?

**A**: 目前不行。如需改變，編輯 `main.py` 最上方:
```python
EXCEL_FILE = "新檔名.xlsx"
TEMPLATE_FILE = "新範本.docx"
```
